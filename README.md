# DockLike alignment screenshots

Visual examples for [m417z/my-windhawk-mods#102](https://github.com/m417z/my-windhawk-mods/pull/102).

These screenshots show the installed local prototype on Windows 11 build 26100.9711, with custom cosmetic overrides. The prototype uses the same alignment and tray-width layout expressions proposed in the PR, with a companion mod supplying the Windows alignment setting.

The integrated Taskbar Styler implementation in the PR has not yet been loaded into Explorer. These images illustrate the intended behavior of the proposal; they do not establish runtime validation of that integrated implementation.

- `docklike-center-desktop.png`: desktop with Windows taskbar icon alignment set to Center.
- `docklike-left-desktop.png`: desktop with Windows taskbar icon alignment set to Left.
- `docklike-center-compact.png`: centered layout with fewer app buttons and a narrower tray.

Captured and supplied by the contributor on October 28, 2026. The original PNGs are published without cropping, retouching, or compositing.
